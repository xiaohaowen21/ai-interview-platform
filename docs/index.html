AI Interview Platform

智能简历分析、AI 模拟笔试、语音面试、知识库问答 —— 一套完整的开源面试辅导平台

⭐ GitHub 仓库 了解功能 →

核心功能

围绕「上传简历 → AI 分析 → 模拟面试 → 知识库辅助」的完整链路设计

📄

简历分析

支持 PDF/DOCX/TXT 格式上传，AI 自动解析并生成结构化分析报告与多维度评分。

✏️

简历优化

基于简历内容和岗位需求，AI 生成优化版本并支持 PDF 导出，一键下载。

📝

模拟笔试

AI 围绕简历自动出题，用户作答后系统自动批改评分，检验真实水平。

🎙️

语音面试

支持多角色面试官风格切换，语音输入 + 语音播报，流式交互体验。

📚

知识库问答

上传资料构建知识库，向量化检索 + RAG 问答，面试准备的好帮手。

⚙️

管理后台

用户管理、AI 接口配置、面试官头像管理、首页素材配置，集中管理。
