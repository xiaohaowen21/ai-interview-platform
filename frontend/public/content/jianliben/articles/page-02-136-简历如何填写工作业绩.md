# 简历如何填写工作业绩？

- 来源：https://www.jianliben.com/article/detail/136
- 作者： 简历本
- 发布时间： 11月04日
- 分类：求职指南
- 阅读量：74119人阅读

> 示例一
工作期间主要业绩有：
1. 改组了整个服务部分，使整个服务的工作效率提高5%；
2. 提出新的工作流程，在减少工作压力的同时，提高了员工的生产能力；
3. 将原来无利润的存货以10万美金的价格成交；
4. 开发了销售和市场项目，使购物中心的利润提高了33个百分点；
5. 通过对公司产品和公司形象的重新定位，使公司的股票价格在9个月内翻了5翻；
6. 使邮政业务量提高9个百分点，从84%提高到历史最高纪录93%，而标准工作量则为74%。
> 示例二
工作期间主要业绩有：
1. 参与珠三角区域适合自动化行业多品种、少批量的供应链探索，通过开发，审核并技术支持建立了本地供应商数据库，遴选出钣金、机械加工、表面处理、PCBA、线材等优质供应商，成功开发了5个新的核心模块供应商到本地合格供应商清单；
2. 提升全自动锡膏印刷机设备对齐的工序能力到行业领先水平，从CPK2.0到2.3，并保证大于95%的首次合格率；
3. 关于可再生能源事业部，成功导入了PVP1200自动化生产线、PVP Eclipse 打印机到中国工厂；
4. 关于表面贴装事业部，成功导入了行业内打印质量测试方法、ProActiv、 ProDEK、 OTS传输导轨系统、锡膏自动分配器等高端产品或工艺；
5. 主导绿带项目提升设备打印质量【高度、对齐、共面性】首次合格率从26%到88%。建立供应商表现评比系统并推动其持续改善品质问题，每年按照20%降低供应商的品质不良和浪费工时。
> 示例三
工作期间主要业绩有：
1. 任职期间，建设了本公司的企业内部与互联网的网站，打开企业的知名度，受到领导的表彰；
2. 参与完成了公司项目，该项目投入后使用，具有显著的经济效益，年节约资金约150万元；
3. 主持完成了总公司的新系统，实现无纸化办公；
4. 采用多层开发方式优化大数据的统计和查询分析，对现有记事本数据批量快速导入SQL Server并结合Excel pdf编程技术对系统开发实现。
> 示例四
接手信贷工作以来，本人各项年度任务完成情况较好。截止今年六月底
1. 个人揽存13.5万元，完成年度任务的94%；
2. 收回正常贷款39万元，完成年度任务的 86%，比去年同期多收5万元；
3. 收回逾期贷款12万元，完成年度任务的229%，比去年同期多收5.5万元；
4. 收回呆滞贷款2.9万元，完成任务的54%，比去年同期多收1.6万元；
5. 收回利息4.9万元，完成年度任务的29.5%，比去年同期多收2.1万元；
6. 发放贷款59万元，完成年度任务的89%，比去年同期多增29万元。
